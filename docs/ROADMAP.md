**ROADMAP.md**

**Overall Goal**  
Build a reusable Rust orbital math library while learning Rust and real orbital mechanics through the game Delta Wrecker.

**Phase 1 – Near-Circular Operations**
- 2D view, very low eccentricity (e < 0.05)
- Simple Hohmann transfers
- Basic propagator and instantaneous burns
- Simple grappling minigame
- Deliver debris to Pre-Graveyard Belt

**Learning Focus:** Basic orbital elements, simple propagation, Rust + PyO3 setup

**Phase 2 – Eccentric Operations**
- Increase allowed eccentricity
- Implement Kepler’s equation
- Proper eccentric orbit propagation
- COLA detection and warnings
- Salvage runs in the dangerous belt

**Learning Focus:** Kepler’s equation, true anomaly, better burn planning

**Phase 3 – Inclined & Advanced Operations**
- Add inclination (move to 3D view)
- Advanced COLA analysis
- Towing with attached mass and thrust limits
- High-value recovery missions

**Learning Focus:** Inclined orbits, precision maneuvering, advanced Rust patterns
